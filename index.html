What I do

Eight ways I usually get pulled into a Shopify build — from a first theme to the fix nobody else wanted to touch.

01

Shopify theme development

Themes built from the ground up in Liquid — semantic markup, sensible schema, and a structure your team can extend without fear.

02

Custom sections & blocks

Reusable, schema-driven sections with real merchant controls, so marketing ships landing pages without a developer in the loop.

03

Store customisation

Bending a premium theme to fit the brand: bespoke product pages, cart drawers, filters and the details that make a store feel custom.

04

Ecommerce UI development

Pixel-accurate front-end from Figma, responsive to 320px, accessible by default, and animated only where it helps the shopper.

05

Third-party app integration

Reviews, subscriptions, loyalty, search and ERP connectors wired in cleanly — with the leftover scripts removed, not stacked.

06

Performance optimisation

Auditing what actually blocks the render: script budgets, image strategy, Liquid loops, and measurable Core Web Vitals gains.

07

Shopify API integration

Storefront and Admin API work — live inventory, custom cart logic, bulk data flows and headless components where they earn their keep.

08

Conversion-focused UX

Fewer steps to checkout: clearer variant states, honest shipping information, faster search and cart flows tested against real behaviour.

How I work

Five stages, no mystery. You always know what’s being built and what happens next.

  1. 01

    Discover

    Understand the business goals, the audience and what the store has to do that a template can’t.

  2. 02

    Design

    Translate layouts into a scalable ecommerce structure — sections, states and edge cases mapped before code.

  3. 03

    Develop

    Build custom sections, Liquid logic and interactions in a theme branch you can preview at any point.

  4. 04

    Optimise

    Tune performance, responsiveness and usability until the numbers and the feel both hold up.

  5. 05

    Launch

    QA across devices, final checks, deployment — and a handover the team can actually use.
